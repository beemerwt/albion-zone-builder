# Agent Instructions

- This project uses Prettier for formatting supported source/config/documentation files.
- Do not manually format supported file types; use Prettier.
- After making code changes, run:
  - `npm run format`
  - `npm run format:check`
- Before final response, also run relevant existing checks such as lint/tests when available.
- If a script does not exist or cannot be run, explain that clearly instead of inventing commands.
